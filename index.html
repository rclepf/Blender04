01

O Shader Editor

Materiais no Blender são construídos visualmente, conectando "nodes" (nós) que representam propriedades e operações — nada de escrever código de shader na mão.

Onde encontrar

Workspace "Shading" no topo da tela, ou qualquer painel trocado para "Shader Editor". Selecione o objeto para ver/editar seu material.

Adicionar um node

Shift+A dentro do editor abre o menu de nodes — texturas, conversores, shaders, etc.

Conectar nodes

Arraste de uma saída (bolinha à direita de um node) até uma entrada (bolinha à esquerda de outro) para criar a conexão.

Slots de material

Um objeto pode ter vários materiais em slots diferentes (Properties → Material). Faces específicas são atribuídas a cada slot em Edit Mode.

02

O que é PBR, na prática

PBR (Physically Based Rendering) é um padrão que descreve superfícies usando propriedades físicas reais, em vez de "truques" de iluminação artesanais. O resultado: o mesmo material se comporta de forma consistente e realista sob qualquer luz — e, crucialmente, os mesmos mapas PBR funcionam tanto no Blender quanto na engine de jogo (Unity, Unreal, Godot).

Um material PBR completo é descrito por um pequeno conjunto de imagens (chamadas de "maps" ou "texturas"), cada uma controlando um aspecto diferente da superfície:

Base Color / Albedo

A cor "crua" da superfície, sem sombra nem brilho — só o pigmento. No baú: o tom marrom da madeira, o cinza do metal.

Roughness

O quão espalhado é o reflexo de luz. Preto = espelhado, branco = fosco. Madeira desgastada tende a ser mais rugosa que metal polido.

Metallic

Define se a superfície se comporta como metal (branco) ou não-metal/dielétrico (preto). Quase sempre é 0 ou 1 — raramente um valor intermediário.

Normal Map

Simula detalhes de relevo (arranhões, veios de madeira, rebites) sem adicionar geometria real — essencial para manter o baú leve em polígonos.

Conexão com o material Freeware/Substance

Se sua turma usa Substance 3D Painter (ou a alternativa freeware, texturização no Blender), é exatamente esse conjunto de mapas que a ferramenta exporta — o Shader Editor do Blender é onde esses mapas são "montados" de volta num material completo.

03

O node Principled BSDF

Um único node resume praticamente todo o padrão PBR — é o node padrão de qualquer material novo no Blender.

Image Texture
  • Base Color
→
Principled BSDF
  • Base Color
  • Metallic
  • Roughness
  • Normal
  • Alpha
→
Material Output
  • Surface

Roughness e Metallic aceitam tanto um valor numérico simples (arrastando o slider) quanto uma textura conectada (para variar por região da superfície):

0.0 (espelhado)
1.0 (totalmente fosco)
Normal maps têm um espaço de cor diferente

Ao conectar uma imagem de Normal Map, ligue-a através de um node "Normal Map" antes do Principled BSDF, e na Image Texture troque o Color Space de "sRGB" para "Non-Color" — normal maps não são "cores" no sentido tradicional, e o Blender precisa saber disso para interpretar os valores corretamente.

04

Guia passo a passo — os dois materiais do baú

Continue a partir de bau_v03.blend do Site 3. Vamos criar um material de madeira e um de metal.

1

Crie o material "Madeira_Bau"

Com Bau_Corpo selecionado, vá em Properties → Material → New. Renomeie o material para Madeira_Bau no campo de nome.

2

Traga uma textura de madeira

No Shader Editor, Shift+A → Texture → Image Texture. Carregue uma imagem de madeira (de uma biblioteca livre, ex. ambientCG ou Poly Haven) e conecte a saída Color na entrada Base Color do Principled BSDF.

Por quê: sem uma Image Texture conectada, a UV feita no Site 3 não tem efeito nenhum — a cor fica uniforme.

3

Ajuste roughness manualmente (ou com mapa)

Se a textura baixada já incluir um mapa de roughness, conecte-o (com Color Space em Non-Color). Caso contrário, ajuste o slider de Roughness do Principled BSDF para algo entre 0.5 e 0.7 — madeira não é espelhada, mas também não é 100% fosca.

4

Crie o segundo slot: "Metal_Bau"

Ainda no Bau_Corpo, adicione um segundo slot de material (botão + na lista de materiais) e crie Metal_Bau com Metallic = 1 e Roughness em torno de 0.3.

5

Atribua as faces de reforço ao metal

Em Edit Mode, modo face, selecione as faixas/cantoneiras que representam reforços metálicos, selecione o slot Metal_Bau na lista e clique em Assign.

Por quê: um objeto pode ter várias regiões com materiais diferentes — não é preciso separar em objetos novos para isso.

6

Aplique material equivalente na tampa

Repita o processo (ou reutilize os mesmos materiais, já criados) no Bau_Tampa — como a UV da tampa foi empacotada no Site 3 junto com o corpo, ela deve encaixar visualmente com a textura de madeira.

05

Problemas comuns e como resolver

Problema

A textura aparece rosa/magenta no objeto.

Causa provável

Caminho da imagem quebrado (arquivo movido ou não empacotado). Reconecte a Image Texture ou use File → External Data → Pack Resources.

Problema

A textura aparece esticada de um jeito diferente do esperado no viewport.

Causa provável

Confira se há um node "UV Map" explícito apontando para o mapa correto — em objetos com múltiplos UV maps, o Blender pode não escolher o certo automaticamente.

Problema

O metal parece plástico fosco, não metálico.

Causa provável

Metallic não está em 1.0, ou a cena tem pouca luz/reflexo ambiente para o metal refletir. Confira também o Roughness — metal muito rugoso perde o brilho característico.

Problema

Faces do reforço metálico não mudam ao clicar Assign.

Causa provável

Nenhuma face estava selecionada no momento do clique, ou o slot errado estava ativo na lista de materiais. Refaça a seleção em Edit Mode antes de clicar Assign.
